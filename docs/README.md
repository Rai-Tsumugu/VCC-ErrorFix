# VCC ErrorFix MCP Bridge

VRChat Creator Companion (VCC) 用パッケージリポジトリ

## インストール方法

VCC を開き、**Settings → Packages → Add Repository** から以下の URL を追加してください：

```
https://rai-tsumugu.github.io/VCC-ErrorFix/index.json
```

その後、対象プロジェクトの **Manage Packages** から `VCC ErrorFix MCP Bridge` をインストールできます。

詳細は [メインリポジトリ](https://github.com/Rai-Tsumugu/VCC-ErrorFix) をご覧ください。
