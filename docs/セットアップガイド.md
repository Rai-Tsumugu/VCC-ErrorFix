# VCC ErrorFix セットアップガイド
### ～ プログラムが初めてのクリエイター向け ～

このガイドでは、**VCC ErrorFix** を使えるようにするまでの手順を、  
一つひとつ丁寧に説明します。  
難しいことは一切ありません。順番通りに進めれば大丈夫です！

---

## このツールでできること

Unity でスクリプトのエラーが出たとき、Claude（AI）が自動でエラーを読み取り、  
「ここがこうなっているから直してみて」と教えてくれるようになります。

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│   Unity でエラー発生                                    │
│         │                                               │
│         ▼                                               │
│   VCC ErrorFix がエラーを記録                           │
│         │                                               │
│         ▼                                               │
│   Claude AI がエラーを分析・修正案を提示                │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

---

## 準備するもの（チェックリスト）

セットアップを始める前に、以下が揃っているか確認してください。

- [ ] **Unity** がインストールされている
- [ ] **VCC**（VRChat Creator Companion）がインストールされている
- [ ] **Visual Studio Code**（VS Code）がインストールされている
- [ ] **Node.js** がインストールされている　← まだの方は次のステップで行います

---

## STEP 0 ： Node.js をインストールする

> すでにインストール済みの方は STEP 1 へ進んでください。

**Node.js** はこのツールの「エンジン」部分を動かすために必要なソフトです。  
インストールするだけで OK で、プログラムを書く必要はありません。

### ① Node.js の公式サイトを開く

ブラウザで `https://nodejs.org/ja/` にアクセスします。

```
┌────────────────────────────────────────────────┐
│  Node.js 公式サイト                            │
│                                                │
│   ┌──────────────────┐  ┌──────────────────┐  │
│   │  20.x.x LTS      │  │  最新版           │  │
│   │  (推奨版)  ← ★  │  │                  │  │
│   └──────────────────┘  └──────────────────┘  │
│                                                │
│  ★「LTS（推奨版）」のボタンをクリック          │
└────────────────────────────────────────────────┘
```

### ② インストーラーを実行する

ダウンロードしたファイル（`.msi` または `.pkg`）をダブルクリックして、  
「次へ」を押し続けてインストールを完了させます。

### ③ インストールできているか確認する

**Windows の場合:**  
スタートメニューで「コマンドプロンプト」を検索して開きます。

**Mac の場合:**  
「アプリケーション」→「ユーティリティ」→「ターミナル」を開きます。

開いたら以下を **そのままコピーして貼り付け** て、Enter を押します。

```
node --version
```

以下のように数字が表示されれば成功です！（数字は異なっても OK）

```
┌────────────────────────────────────┐
│  > node --version                  │
│  v20.18.0          ← こんな表示    │
└────────────────────────────────────┘
```

> ⚠️ `node is not recognized` などのエラーが出た場合は、  
> パソコンを再起動してからもう一度試してみてください。

## STEP 1 ： VCC でパッケージを追加する

### ① VCC を開く

VCC（VRChat Creator Companion）を起動します。

### ② プロジェクトを選ぶ

一覧から VCC ErrorFix を使いたいプロジェクトの  
**「Manage Project」** をクリックします。

```
┌──────────────────────────────────────────────────────────┐
│  VRChat Creator Companion                                │
│                                                          │
│  Projects                                                │
│  ┌────────────────────────────────────────────────────┐  │
│  │  MyWorld               Unity 2022.3   ← 自分のPJ  │  │
│  │                        [Manage Project] ← クリック │  │
│  └────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────┘
```

### ③ パッケージを追加する

「Packages」タブで **VCC ErrorFix MCP Bridge** を探して  
**「＋ Add」** ボタンをクリックします。

```
┌──────────────────────────────────────────────────────────┐
│  Manage Project: MyWorld                                 │
│                                                          │
│  Packages タブ                                           │
│  ┌────────────────────────────────────────────────────┐  │
│  │  VCC ErrorFix MCP Bridge          v0.1.0    [+ Add]│ ←クリック
│  └────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────┘
```

### ④ Unity でプロジェクトを開く

VCC の「Open Project」ボタンからプロジェクトを Unity で開きます。  
Unity が起動したら STEP 2 に進みます。

## STEP 3 ： MCP サーバーをビルドする

この作業は **最初の1回だけ** 行えば OK です。

### ① パッケージのフォルダを開く

エクスプローラー（Windows）またはFinder（Mac）で、  
Unity プロジェクトのフォルダを開きます。

プロジェクトの中に **`Packages`** フォルダがあります。  
その中の `com.rai-tsumugu.vcc-errorfix` → `mcp-server` フォルダを開きます。

```
📁 MyWorld（プロジェクトフォルダ）
  ├── 📁 Assets
  ├── 📁 Library
  ├── 📁 Packages
  │     └── 📁 com.rai-tsumugu.vcc-errorfix
  │               └── 📁 mcp-server  ← ここ！
  └── ...
```

### ② ターミナルを `mcp-server` フォルダで開く

**Windows の場合:**  
`mcp-server` フォルダを開いた状態で、  
アドレスバーに `cmd` と入力して Enter を押します。

```
┌─────────────────────────────────────────────────────────┐
│  📁 mcp-server                                          │
│  アドレスバー: cmd  ← ここに入力して Enter             │
└─────────────────────────────────────────────────────────┘
```

**Mac の場合:**  
`mcp-server` フォルダを右クリック →「フォルダに新規ターミナルタブ」をクリックします。

### ③ コマンドを実行する

ターミナル（黒い画面）に以下を **1行ずつ** コピー＆ペーストして、  
Enter を押してください。

**まず1行目：**
```
npm install
```

しばらく待ちます。こんな表示が出れば OK です。

```
┌─────────────────────────────────────────────────────────┐
│  > npm install                                          │
│                                                         │
│  added 25 packages in 3s  ← こんな感じの表示が出ればOK │
└─────────────────────────────────────────────────────────┘
```

**次に2行目：**
```
npm run build
```

こんな表示が出れば成功です！

```
┌─────────────────────────────────────────────────────────┐
│  > npm run build                                        │
│                                                         │
│  > vcc-errorfix-mcp@0.1.0 build                        │
│  > tsc                                                  │
│                                                         │
│  ＄_              ← エラーなく終わればOK！              │
└─────────────────────────────────────────────────────────┘
```

> ⚠️ **`error TS...` のような赤い文字が出た場合**  
> Node.js のバージョンが古い可能性があります。  
> STEP 0 に戻り、Node.js を再インストールしてください。

## うまくいかないときは

### ❶ ダッシュボードが「● Stopped（赤）」のまま

**原因:** 同じポートを別のアプリが使用している可能性があります。

**解決策:**
1. ダッシュボードの Port 欄の数字を `7301` などに変更する  
2. **Apply** ボタンをクリックする  
3. **● Running（緑）** になれば OK

```
  Port [7301] [Apply] ← 数字を変えて Apply
```

---

### ❷ `npm install` でエラーが出る

**原因:** Node.js が正しくインストールされていない可能性があります。

**解決策:**
1. STEP 0 の手順で `node --version` を実行し、バージョンが表示されるか確認する
2. 表示されない場合は Node.js を再インストールし、PCを再起動する
3. もう一度 `npm install` を試す

---

### ❸ `npm run build` でエラーが出る

**原因:** Node.js のバージョンが 20 未満の可能性があります。

**解決策:**
1. ターミナルで `node --version` を実行する
2. `v18...` や `v16...` のように 20 より前のバージョンが表示された場合は  
   Node.js 公式サイト（`https://nodejs.org/ja/`）から **LTS 版**を再インストールする

---

### ❹ Claude がエラーを取得できないと言う

**原因:** Unity Editor が閉じているか、サーバーが停止しています。

**解決策:**
1. **Unity Editor が起動していること** を確認する
2. Unity のダッシュボードで **● Running（緑）** になっていることを確認する
3. Unity が起動していない場合は Unity を起動してから再度 Claude に聞く

## セットアップ完了後の流れ

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  1. Unity でスクリプトを編集                            │
│            │                                            │
│            ▼                                            │
│  2. コンパイルエラーが発生                              │
│     （ダッシュボードに自動表示 ※設定した場合）         │
│            │                                            │
│            ▼                                            │
│  3. VS Code で Claude に「エラーを確認して」と伝える   │
│            │                                            │
│            ▼                                            │
│  4. Claude がエラーを読み取り・修正案を提示             │
│            │                                            │
│            ▼                                            │
│  5. Claude の提案をもとにスクリプトを修正               │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

---

> 💡 **ヒント:** エラー修正後は Unity ダッシュボードの **Clear All** ボタン  
> または Claude に「エラーをクリアして」と伝えることで、  
> エラーリストをリセットできます。
